# 第 23 晚：Pseudo-Boolean、MaxSAT 与线性搜索

## 学习目标

把软子句松弛成目标，做小型 MaxSAT 与 PB 界迭代。

## 前置回忆（0–5 分钟）

基数编码；优化上下界；SAT oracle。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

MaxSAT 要最大化满足软子句数（或最小化违反权重），硬子句必须满足。给每个软子句 C_i 加 relaxation literal r_i 得 C_i∨r_i，再最小化 Σw_i r_i。最简单线性搜索不断加更紧的 PB/基数上界并调用 SAT；core-guided 算法利用 UNSAT core 更聪明地松弛。SAT 与优化的证书不同，最优性需同时给可行上界模型和“更好目标不可能”的 UNSAT 证明。教学代码穷举作为 oracle，着重理解建模与界。

**核心不变量：** r_i=true 精确表示允许对应软子句被违反；最优值上下界最终相遇。

**高频陷阱：** 硬子句也可松弛；权重方向反；找到好模型就声称最优。
