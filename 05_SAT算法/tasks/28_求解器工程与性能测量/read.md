# 第 28 晚：内存布局、热路径与可复现基准

## 学习目标

用profile和操作计数定位传播热路径，避免只凭墙钟优化。

## 前置回忆（0–5 分钟）

watch lists；缓存局部性；统计学基础。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

现代 SAT 性能很大部分来自工程：紧凑文字编码、连续子句 arena、二元子句专门路径、分支预测、减少分配和定期垃圾回收。Python 教学实现不能复制 C++ 吞吐，但可用 `cProfile`、传播访问数、分配计数与固定基准建立方法。墙钟受机器噪声影响，应 warm-up、重复、报告中位数/分位数并固定解释器版本。优化前必须有差分 oracle；错误的快求解器没有价值。

**核心不变量：** 优化前后结果与证书一致；所有计数在同一工作负载与口径下测量。

**高频陷阱：** 只测一个小样例；把解析时间混入求解时间；为速度删断言却无外部验证。

## 代码实战（25–50 分钟）

在本任务目录运行 `python practice.py`。比较复制式DPLL和trail式实现的分配/子句检查数，用profile列前三热点。 找到文件末尾的“动手改造”，每次只改变一个因素，并保留全部断言与固定随机种子。

## 边界测试与验收（50–60 分钟）

50–57 分钟加入最小正例、最小反例与一个边界输入；57–60 分钟闭卷写“定义 / 不变量 / 本实验不能证明什么”各一句。

验收标准：给出可复现环境与种子；答案一致；结论限定于样本。
