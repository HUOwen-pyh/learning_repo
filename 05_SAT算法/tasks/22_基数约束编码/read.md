# 第 22 晚：基数约束：pairwise、sequential 与 cardinality network

## 学习目标

编码 at-most-one/exactly-k，比较子句/辅助变量与传播强度。

## 前置回忆（0–5 分钟）

Tseitin；组合数；单位传播。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

“至多一个变量为真”可用所有二元互斥子句，O(n²) 且传播强；Sinz sequential counter 用 O(n) 辅助变量/子句编码前缀是否已见真。一般 at-most-k 可用计数器、totalizer、sorting/cardinality networks 等，在尺寸、增量性与 propagation consistency 间权衡。Exactly-one=at-least-one 加 at-most-one。编码验收必须对所有原变量赋值检查：合法赋值存在辅助扩展，非法赋值没有。

**核心不变量：** 投影到原变量后，CNF 可满足恰好对应基数条件；辅助变量不得限制合法原赋值。

**高频陷阱：** 只测试一个辅助赋值；序列首尾边界；把最少子句等同传播最好。

50–57 分钟加入最小正例、最小反例与一个边界输入；57–60 分钟闭卷写“定义 / 不变量 / 本实验不能证明什么”各一句。
