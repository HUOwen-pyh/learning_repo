# 第 15 晚：Subsumption、SSR 与阻塞子句消去

## 学习目标

实现三种预处理规则并分别说明保持等价还是保持可满足。

## 前置回忆（0–5 分钟）

集合包含；resolution；模型重建。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

若 C⊆D，则 D 被 C subsume 可删，保持逻辑等价。Self-subsuming resolution 在特定互补文字条件下用更短 resolvent 替换子句，也可保持等价。阻塞子句 C 对文字 l blocked，若 C 与所有含 ¬l 的子句在 l 上的 resolvent 都是重言式，则删除 C 保持可满足性但未必保持全部模型；重建时若 C 不满足，可设置 l 对应变量修复。检查成本依赖 occurrence lists。规则应用到固定点时需谨慎更新索引。

**核心不变量：** subsumption/SSR 的每个替换有蕴含证明；BCE 删除要记录阻塞文字供模型重建。

**高频陷阱：** 子集方向反；只检查一个互补子句就判 blocked；把 BCE 称逻辑等价。

## 代码实战（25–50 分钟）

在本任务目录运行 `python practice.py`。实现规则，在 n≤5 上穷举比较等价/等可满足性，并重建 BCE 模型。 找到文件末尾的“动手改造”，每次只改变一个因素，并保留全部断言与固定随机种子。

## 边界测试与验收（50–60 分钟）

50–57 分钟加入最小正例、最小反例与一个边界输入；57–60 分钟闭卷写“定义 / 不变量 / 本实验不能证明什么”各一句。

验收标准：每条规则有正负例；BCE 的模型集合可变化但 SAT 状态不变。
