# 第 18 晚：Resolution、DRAT/LRAT 与可检查 UNSAT 证明

## 学习目标

生成/验证小型 RUP 证明，理解求解与证明检查的信任边界。

## 前置回忆（0–5 分钟）

resolution refutation；单位传播；UNSAT。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

SAT 模型可线性检查；UNSAT 需要证书。DRAT 允许添加满足 RAT 条件的子句并删除子句，表达力强但检查器需搜索提示；LRAT 给出显式提示，适合高可信/形式化检查。RUP 添加 C 的判据是数据库加上 C 中每个文字的否定单位传播出冲突，因此 C 被蕴含。以空子句结束即证明 UNSAT。竞赛主赛道要求 UNSAT 输出 proof，强调答案必须可验证。

**核心不变量：** 检查器只信原 CNF 与每步规则；空子句只有在合法步骤后出现。

**高频陷阱：** 用求解器自身再次求解代替证书检查；忽略删除后的引用；把任意学习子句当RUP。

## 代码实战（25–50 分钟）

在本任务目录运行 `python practice.py`。写RUP checker，验证一条小 refutation，再篡改提示/子句确认拒绝。 找到文件末尾的“动手改造”，每次只改变一个因素，并保留全部断言与固定随机种子。

## 边界测试与验收（50–60 分钟）

50–57 分钟加入最小正例、最小反例与一个边界输入；57–60 分钟闭卷写“定义 / 不变量 / 本实验不能证明什么”各一句。

验收标准：合法证明通过；篡改失败；无需搜索完整模型空间。
