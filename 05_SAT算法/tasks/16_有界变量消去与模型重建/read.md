# 第 16 晚：有界变量消去、Resolution 与模型重建

## 学习目标

实现 Davis–Putnam 式变量消去并控制 resolvent 爆炸。

## 前置回忆（0–5 分钟）

resolution；预处理日志；模型投影。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

消去变量 x 时，收集含 x 的正子句 P 与含 ¬x 的负子句 N，加入每对在 x 上的非重言 resolvent，再删除 P∪N。结果对剩余变量是存在量化 ∃x F，保持可满足性。若 resolvent 数/文字量增长太多就跳过，称 bounded variable elimination。模型重建逆序查看被删子句：若当前剩余赋值不能同时满足它们，选择能修复的一极性；正确日志保证至少一种可行。

**核心不变量：** 消去后公式等价于对被消变量存在量化；逆序重建得到原公式模型。

**高频陷阱：** 保留 pivot；加入重言 resolvent；消去顺序日志正向重建。

## 代码实战（25–50 分钟）

在本任务目录运行 `python practice.py`。消去一个变量，穷举比较投影模型，并从简化模型重建原模型。 找到文件末尾的“动手改造”，每次只改变一个因素，并保留全部断言与固定随机种子。
