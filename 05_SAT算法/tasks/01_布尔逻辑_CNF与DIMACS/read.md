# 第 01 晚：布尔逻辑、CNF 与 DIMACS

## 学习目标

统一变量、文字、子句、CNF、模型的表示，并可靠解析/输出 DIMACS。

## 前置回忆（0–5 分钟）

复习布尔运算、德摩根律、集合与字典。 先闭卷写定义和一个最小例子，再读下文纠正。

## 精读正文（5–25 分钟）

SAT 输入是命题公式，工程求解器通常接收 CNF：子句是文字的析取，公式是子句的合取。整数编码中正 v 表示 x_v，负 -v 表示否定；空子句立即矛盾，空 CNF 则为真。DIMACS 首行 `p cnf n m`，每个子句以 0 结束，注释以 c 开头。模型必须逐子句验证，不能只相信求解器的 SAT 字样。解析器还要检测越界变量、遗漏 0 和声明计数不一致。本晚建立整个课程共享的语义口径。

**核心不变量：** 一个模型满足 CNF 当且仅当每个子句至少有一个取真的文字；空集合的合取为真，空析取为假。

**高频陷阱：** 把变量 0 当普通变量；漏掉空子句；只检查模型中出现为真的变量而忽略负文字。

## 代码实战（25–50 分钟）

在本任务目录运行 `python practice.py`。解析内置 DIMACS，逐子句求值，再序列化并重解析；补充空 CNF 与空子句测试。 找到文件末尾的“动手改造”，每次只改变一个因素，并保留全部断言与固定随机种子。

## 边界测试与验收（50–60 分钟）

50–57 分钟加入最小正例、最小反例与一个边界输入；57–60 分钟闭卷写“定义 / 不变量 / 本实验不能证明什么”各一句。

验收标准：能手算一个模型；round-trip 后语义不变；非法输入被拒绝。
