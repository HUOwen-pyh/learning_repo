## 精读正文

Trie 的每条边表示一个字符，从根到节点拼成前缀。节点的 `terminal` 表示该前缀本身是否为键；`subtree_words` 表示以此前缀开头的键数。查询/插入长度 (L) 的键耗时 (O(L))，与集合键数无关，但字符映射与 Unicode 规范化是实际成本。

插入只在首次出现键时增加路径各节点计数；删除相反，并可在子树词数归零时剪枝。自动补全先走到前缀节点，再按字符序 DFS。若孩子用字典，空间与实际边数成正比；固定小字母表可用数组换更好常数。

不变量是：每个节点的子树词数等于自身终止贡献加孩子之和，且所有孩子边标签互异。陷阱：空串位于根；重复插入导致计数膨胀；按 Python code point 而非用户感知字符；大小写/Unicode 组合形式不统一。生产系统应先定义规范化层。
