# 第 2 晚：摊还分析与势能法

## 学习目标

- 用聚合、记账、势能三种语言分析同一操作序列。
- 推导倍增动态数组 `append` 的均摊 (O(1))。
- 区分摊还保证与概率期望。

## 前置回忆

最坏复杂度针对单次还是序列？长度为 8 的满数组追加一个元素，需要搬多少个旧元素？若容量每次只加 1，会发生什么？

## 精读正文

动态数组满时把容量乘 2。第 (i) 次扩容搬运 (1,2,4,\ldots) 个元素；到完成 (n) 次追加为止，总搬运少于 (2n)，再加 (n) 次写入，总成本小于 (3n)。这是**聚合法**。

记账法可向每次追加收取 3 个代币：1 个支付当前写入，剩余代币储存在元素上支付未来搬运。势能法则定义状态的“预付工作”。取 \(\Phi=2\,\text{size}-\text{capacity}\)（空结构作适当归零），摊还成本 \(\hat c_i=c_i+\Phi_i-\Phi_{i-1}\)。普通追加和扩容追加都可被常数界住；跨整个序列的势能变化望远镜相消。

不变量是 `0 <= size <= capacity` 且逻辑序列等于底层前 `size` 个槽。倍增因子越小，空间浪费少但复制多；越大则相反。因子必须严格大于 1 才能维持几何级数。陷阱：摊还 (O(1)) 不意味着每次延迟都小；实时系统可能需要增量迁移。它也不是期望值，不依赖随机输入。
