# 第 22 晚：持久化与路径复制

## 学习目标

- 区分部分持久化、完全持久化与可汇合持久化。
- 用路径复制保存线段树历史版本。
- 理解结构共享、不变对象与版本根。

## 前置回忆

点更新在线段树中触碰多少节点？若不修改旧节点，只复制更新路径，会共享哪些子树？Python 浅拷贝是否自动保证不可变？

## 精读正文

持久化结构保留旧版本可查询。部分持久化允许更新最新版本、查询任意版本；完全持久化允许从任意旧版本分叉更新；可汇合持久化还允许合并版本，语义更难。脚本的路径复制线段树是完全持久化：每次点更新输入任意根，沿根到叶复制 (O(\log n)) 个节点，未触及子树直接共享。

不变量是每个 Node 创建后不再修改，`total` 等于两孩子摘要或叶值；版本只是一组根引用。查询旧根不会看到新更新。构建 (O(n))，每次更新时间与新增空间均 (O(\log n))，区间查询 (O(\log n))。持久化不是数据库 durability：进程退出后对象仍消失；也不自动解决多线程发布与内存回收。

陷阱：在共享节点上就地写导致所有版本被污染；把整个树深拷贝成 (O(n))；版本 ID 与根生命周期混乱；存大量 Python 对象的常数很大。若要 range update，lazy tag 也必须复制并保持不可变语义。

## 代码任务

运行脚本；实现 `diff(root_a, root_b, l, r)`。进阶构建第 1..i 个元素的频率版本，做静态区间第 k 小。

## 验收标准

- 从旧版本分叉后，两个新版本互不影响。
- 新增节点数与更新次数乘 (O(\log n)) 一致。
- 能解释不可变节点是正确性的关键而非语法偏好。
