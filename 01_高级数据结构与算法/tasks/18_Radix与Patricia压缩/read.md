# 第 18 晚：Radix / Patricia 压缩 Trie

- 理解 Patricia 的分支位思想及空间优势。

## 前置回忆

普通 Trie 对只有一个孩子的长链存了多少节点？插入词与某条边只共享一部分前缀时，需要产生哪些边？压缩后复杂度还应按什么衡量？

## 精读正文

Radix tree 把连续单孩子路径合成一条字符串边。节点孩子的首字符互异；任意非空边标签连接两个显式分支/终止点。查找比较边标签，完整消费后再走下一边。插入遇到部分公共前缀时，把旧边拆成公共前缀中间节点、旧后缀和新后缀，终止可能落在中间节点。

不变量是：边标签非空；同节点外出边首字符互异；路径拼接与键一一对应；非终止的非根节点通常至少两个孩子（否则还能压缩）。若字符串比较按字符计费，查询仍为 (O(L))，不是按边数 (O(\#edges)) 就能忽略标签比较。空间由普通 Trie 的每字符节点降到分支/终止点级，但切片字符串可能复制，工程实现常存原串区间。

Patricia trie 是按“首个不同 bit”分支的压缩二进制 Trie，常用于路由最长前缀匹配；radix tree 也可按字节/若干 bit 分支。陷阱：一个键是另一个键前缀；公共前缀为 0；拆边后字典索引仍须使用新边首字符；Unicode 比较单位要定义。
