# 高级数据结构与算法：30 个夜晚的递进训练

这不是“看完一遍名词”的清单，而是一条以**不变量、复杂度证明、实现、反例和测量**为主线的训练路线。每天投入 60 分钟；先读当天的 `read.md`，再直接运行并改造 `practice.py`。所有代码只使用 Python 3.11+ 标准库，初始版本可直接运行。

## 先修知识与环境

- 能写 Python 函数、类、生成器，理解递归、位运算和 `dataclass`。
- 熟悉数组、链表、栈、队列、普通二叉树和 BFS/DFS。
- 会读 (O(\cdot))、集合与求和符号；知道概率、期望与对数的基本含义。
- 使用 Python 3.11 或更新版本：在某个任务目录运行 `python practice.py`。
- 建议保留一份学习日志：每晚写下“不变量、复杂度、一个失败用例、一次测量”各一句。

## 每晚固定的 60 分钟

1. **0–8 分钟：前置回忆**——不看答案，先回答 `read.md` 中的问题。
2. **8–28 分钟：精读**——手写核心不变量与复杂度推导，不只记接口。
3. **28–52 分钟：代码实战**——运行脚本，读实现，完成至少一个“动手改造”。
4. **52–60 分钟：验收**——运行断言，解释一个陷阱，并记录实验数据。

如果某晚卡住，不要用下一晚挤占它：先将失败输入最小化，再查不变量。60 分钟的目标是完成一个闭环，而不是读尽所有材料。

## 30 晚路线

| 阶段 | 夜晚 | 主题与阶段产物 |
|---|---:|---|
| 分析工具 | 01–03 | 成本模型与实验；摊还分析；随机化、期望与可复现实验 |
| 可合并结构 | 04–07 | 并查集；二叉/多叉堆；二项堆；Fibonacci 堆的惰性思想 |
| 有序字典 | 08–12 | 顺序统计 BST；AVL；红黑/LLRB；Treap；跳表 |
| 概率字典与流摘要 | 13–16 | 开放寻址与扩容；Robin Hood/Cuckoo；Bloom filter；Count-Min Sketch |
| 字典树与区间查询 | 17–21 | Trie；压缩 Radix/Patricia；Fenwick；惰性线段树；稀疏表 RMQ |
| 持久化与树图 | 22–25 | 路径复制持久化；LCA；重链剖分；回滚并查集与离线动态连通性 |

| 综合验收 | 30 | 并发正确性与流式索引综合项目 |

## 学习产出与验收方式

每晚都应能完成以下四件事：

- 用一句话说出结构的核心不变量；
- 给出查询与更新的最坏、均摊或期望复杂度，并明确是哪一种；
- 让当天脚本的断言全部通过，再加入至少一个边界用例；
- 判断何时**不应该**使用该结构。

阶段验收建议：

- **第 7 晚**：能从操作序列而不是单次操作解释摊还界；能比较不同可合并堆。
- **第 12 晚**：给定工作负载，能在 AVL、红黑树、Treap、跳表之间说明选择。
- **第 21 晚**：能从操作是否可逆、是否幂等、是否需要更新来选 Fenwick/线段树/稀疏表。
- **第 25 晚**：能区分在线/离线、部分/完全动态，并说明回滚为何不能配路径压缩。
- **第 30 晚**：综合项目通过确定性测试、随机差分测试和并发烟雾测试；写一页设计复盘。

## 进阶参考与查阅顺序

先读教材章节获得统一符号，再读原始论文理解模型边界，最后看工程实现。

- Cormen, Leiserson, Rivest, Stein, *Introduction to Algorithms*, 4th ed.（分析、堆、红黑树、并查集、摊还分析）。
- Sedgewick & Wayne, [Algorithms, 4th Edition](https://algs4.cs.princeton.edu/home/)（带实现与实验视角）。
- Pat Morin, [Open Data Structures](https://opendatastructures.org/)（免费教材，覆盖随机 BST、散列与外存结构）。
- MIT 6.851, [Advanced Data Structures](https://courses.csail.mit.edu/6.851/)（高级课程讲义与论文入口）。
- Peter Sanders 等, [Algorithm Engineering](https://doi.org/10.1007/978-3-319-49487-6)（把模型、实现和实验连接起来）。

## 如何继续到研究前沿

完成后选择一种“约束”继续深入：并发（linearizability、lock-free、内存回收）、大内存/NUMA、外存/持久内存、succinct/压缩、流式与近似、动态图库。阅读论文时固定回答：计算模型是什么？随机性或摊还藏在哪里？下界与上界是否在同一模型？实验是否覆盖 adversarial workload？代码能否复现？
