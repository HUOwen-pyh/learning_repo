每个学科的 `README.md` 是总纲；任务目录中的 `read.md` 是精确阅读任务书。前五科使用两位编号并配 `practice.py`；第六科使用三位编号，前半段以 `practice.py` 建模，进入 TypeScript/Cordis/Harness 后改用 `practice.ts`。第六科的外部教材、论文和固定版本源码属于当晚必读材料，`read.md` 只负责指定版本、范围、问题和导读，不冒充原文。

## 默认的 150 晚轮转

以 5 晚为一轮，第 k 轮完成五科各自的第 k 个任务：

| 当轮晚次 | 学科 | 第 k 轮要做 |
|---:|---|---|
| 第 1 晚 | 高级数据结构与算法 | `01_高级数据结构与算法/tasks/k_*/` |
| 第 2 晚 | 组合优化 | `02_组合优化/tasks/k_*/` |
| 第 3 晚 | 近似算法 | `03_近似算法/tasks/k_*/` |
| 第 4 晚 | 计算理论 | `04_计算理论/tasks/k_*/` |
| 第 5 晚 | SAT 算法 | `05_SAT算法/tasks/k_*/` |

因此总晚次 `5(k-1)+1...5k` 对应各科第 k 晚。例如总第 47 晚是第 10 轮的组合优化任务。轮转让同一概念从不同角度相遇：NP/归约支撑组合优化和近似；图结构支撑流、匹配和 SAT 中的图算法；SAT 实现又反过来成为计算理论的可运行实例。

若基础薄弱，可先做计算理论 01–13，再回到默认轮转；若线性代数或概率卡住，只补对应知识，不需要推倒重来。

## 每晚严格 60 分钟

- 0–5 分钟：闭卷回忆前置概念。
- 5–25 分钟：读 `read.md`，只摘定义、不变量和一个陷阱。
- 25–50 分钟：运行 `practice.py`，完成文件末尾的“动手改造”。
- 50–57 分钟：补最小正例、最小反例与边界输入。
- 57–60 分钟：写三句话——学会了什么、哪里会错、下一步是什么。

60 分钟到点仍未完成时，把失败输入和当前猜想记入日志；下一次同科任务开始前最多补 15 分钟。不要用一次熬夜替代持续训练。

## 运行与自检

在任意任务目录：

```powershell
python practice.py
```

第六科第 162 晚以后，在安装课程指定的 Node 版本后直接运行：

```powershell
node practice.ts
```

这些独立练习刻意只使用可擦除的 TypeScript 类型语法；Node 22.18+ 可直接执行。真正进入 Harness 仓库后，仍需使用仓库自己的 `pnpm typecheck`、Vitest 与集成门禁，不能把“能直接运行”误当成“完整类型检查通过”。

在课程根目录检查结构和 Python 语法：

```powershell
python validate_course.py
```

执行全部练习（约数十秒，个别机器可能更久）：

```powershell
python validate_course.py --run
```

本机当前的 Windows Store `python` 别名不可用；本项目最终验收实际使用的是：

```powershell
& 'C:\Users\misak\AppData\Local\Python\bin\python.exe' -B validate_course.py --run --timeout 30
```

若你之后修正了 PATH，继续使用较短的 `python ...` 命令即可。

前五科及第六科第 001–161 晚面向 Python 3.11+，只使用标准库；第六科第 162–196 晚改用 TypeScript，以便直接学习目标仓库的类型与插件机制。`validate_course.py --run` 会执行全部 Python 练习，并对 TypeScript 练习做结构检查；TypeScript 的实际运行验收按第六科总纲安装 Node/pnpm 后完成。固定随机实验都使用显式种子，便于复现。

## 学习证据与毕业标准

使用 [学习进度.md](学习进度.md) 勾选进度。每 5 轮做一次闭卷复盘；不要以“读过”作为完成标准。课程结束时应能：

- 为一种高级数据结构说出表示不变量、操作复杂度和退化输入；
- 将现实问题建成组合优化模型，并解释精确、参数化、近似方法的取舍；
- 写出近似比证明的收费、对偶、舍入或概率论证；
- 准确区分可判定性、复杂度类、条件性下界和开放问题；
- 从 DIMACS CNF 到现代 CDCL，解释传播、学习、重启、预处理与验证证书；
- 为一个小语言写出语法、类型规则和操作语义，解释 progress/preservation，并用反例区分错误规则；
- 从半群、幺半群走到函子、自然变换、伴随、Monad、代数效应、Coeffect 与可撤销 effect，能写出定律并运行验证；
- 在固定提交上追踪 DeepSeek Harness 的 plugin tree、turn/tool/session 事件链，并实现一个可卸载、可回放、可故障注入的 Cordis 插件；
- 产出可复现实验：固定数据、随机种子、指标、断言、反例和诚实结论。

“最前沿”任务是研究入口，不宣称在一小时内掌握整篇论文。遇到 P vs NP、Unique Games、一般电路下界、MCSP 完全性等问题时，材料会明确标成开放或条件性结论。
