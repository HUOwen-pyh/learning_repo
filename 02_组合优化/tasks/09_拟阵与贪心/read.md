# 第 09 晚：拟阵、交换公理与贪心刻画

## 学习目标

- 识别遗传性与交换公理，判断独立系统是否为拟阵。
- 证明按权重排序贪心在拟阵上最优。
- 区分 uniform、partition、graphic matroid，并构造非拟阵反例。

## 前置回忆

独立系统 $(E,\mathcal I)$ 满足空集独立且独立集的子集仍独立。回忆 MST 中“不会成环就加边”的 Kruskal。

## 完整精读讲解

拟阵在遗传性外要求交换：若 $A,B$ 都独立且 $|A|<|B|$，存在 $e\in B\setminus A$ 使 $A+e$ 仍独立。它抽象了线性无关和森林。uniform matroid 限制集合大小不超过 $k$；partition matroid 对每组设容量；graphic matroid 的独立集是无环边集。

最大权基贪心按权重降序扫描，能保持独立就加入。证明将贪心基 $G$ 与最优基 $O$ 对齐：第一个不同元素 $g$ 出现时，交换公理/基交换允许用 $g$ 替换 $O$ 中某个尚未选元素；排序保证 $w(g)$ 不小，反复交换不降低最优值，最终变成 $G$。非负权时最大权独立集可扩成基；有负权时要允许停止，否则“基”与“独立集”目标不同。

Rado–Edmonds 定理更强：一个遗传系统对所有权重都能被这种贪心正确求解，当且仅当它是拟阵。背包可行集具有遗传性，却通常不满足交换，所以 value 排序或密度排序都可能失败。两个拟阵的交集也不再由简单贪心解决；二分匹配可视为两个 partition matroid 的交。

复杂度为 $O(|E|\log |E|+|E|T_{\text{oracle}})$，关键是独立性 oracle。陷阱：只检查所有极大集大小相同却忽略限制子集、把“贪心在一个实例成功”当成结构证明、负权强行填满容量。

## 代码任务

写通用独立性 oracle 接口；分别对 partition 和 graphic matroid 运行贪心，并用穷举验证最优；让非拟阵背包实例展示失败。

## 验收标准

- 能逐条验证或推翻交换公理。
- 贪心与穷举在两个拟阵实例一致。
- 至少一个背包反例使简单贪心严格次优。
- 能说明匹配为何不是“直接套拟阵贪心”。
