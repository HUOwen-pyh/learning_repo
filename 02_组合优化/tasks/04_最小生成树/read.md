# 第 04 晚：最小生成树与安全边

## 学习目标

- 用 cut property 与 cycle property 证明贪心安全。
- 实现 Kruskal 的并查集与 Prim 的堆版本。
- 区分生成树、最短路树及不连通图的生成森林。

## 前置回忆

树是连通无环图，$n$ 个点的树恰有 $n-1$ 条边。并查集的 find/path compression 和 union by rank 用于维护连通分量。

## 完整精读讲解

最小生成树（MST）在连通无向加权图中选 $n-1$ 条边使总权最小。它优化全局连通成本，不保证根到各点路径最短。割性质：对任一割，跨割的最轻边属于某棵 MST。证明用交换：若一棵 MST 不含该边，加边产生环，环必有另一条跨割边；用更轻边替换不增成本。若严格更轻则所有 MST 都必须含它。

Kruskal 按边权递增，只加连接不同分量的边；每一步选择的是当前分量割上的安全边。排序 $O(E\log E)$，并查集摊还近常数。Prim 从一个树出发，总取跨当前顶点集的最轻边；二叉堆实现 $O(E\log V)$。权重可为负，因为证明只依赖相对次序。

不连通图没有生成树，Kruskal 会返回最小生成森林，必须显式标注状态。相同权重会导致多解；若想判断唯一性，需检查每个权重批次中是否存在可替换结构，而不能仅看输出。常见陷阱：把有向图直接套 MST、并查集初始化漏点、Prim 把旧堆条目重复计入、只数边不验连通/无环。

## 代码任务

运行 Kruskal 和 Prim，使用独立检查器验证边数、无环、连通和总权；再将一条边删除使图不连通，确认程序报告森林。

## 验收标准

- 能完整复述 cut property 交换论证。
