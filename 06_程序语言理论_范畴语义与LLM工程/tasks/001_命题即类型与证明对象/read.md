# 第 001 晚：命题即类型与证明对象

## 学习目标

把“证明命题”改写为“构造该命题对应类型的值”，并能区分命题、证明对象和证明检查器三层。

## 前置任务

无。只要求会写 Python 函数、元组和 `dataclass`，并记得命题逻辑中的真、假、蕴含。

## 精读导引

先只看“命题—类型、证明—程序”的对应，不必学习 Agda 语法。把 `A → B` 同时读成函数类型和逻辑蕴含；判断一个对象是不是证明，必须由独立的类型/规则检查器决定，而不是看字符串是否像答案。Curry–Howard 是结构对应，不是说任意运行成功的程序都证明了任意命题。

## 必须完成的推导

结论类型：**THEOREM**。在假设表 `Γ` 中已有 `p : P` 时，变量规则给出 `Γ ⊢ p : P`；抽象掉该假设得到 `⊢ λp.p : P → P`。写出这两步，并解释伪造一个结论标签为何不构成推导。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础，不声称目标仓库已经使用证明对象。以后分析 LLM 评测时，要把“模型声称通过”与“独立验证器接受证书”分开；这种生产者/检查器分离正是证明对象视角。
