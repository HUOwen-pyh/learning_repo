# 第 100 晚：积与合取的泛性质

## 学习目标

- 用“存在唯一配对态射”而不是坐标直觉定义范畴积。
- 把合取的引入/消去规则对应到配对与两个投影。

## 前置知识与关联任务

需要 099 的判断—态射解释，以及 095–098 的积对象定义。回忆 Python 二元组只是 `Set` 中积的一个实现。

## 精读导引

遮住集合中的笛卡尔积例子，先只看锥 `X→A`、`X→B`。你要能从任意这对态射构造唯一的 `X→A×B`，并由投影恢复原态射。存在而不唯一的候选不能称为积；对象本身也只在唯一同构意义下确定。

## 必须完成的推导或证明

写出 `Γ⊢s:A`、`Γ⊢t:B` 到 `Γ⊢(s,t):A×B` 的语义，并推导两条 β 方程和一条 η 方程。

## 代码实战

脚本在有限集合上穷举候选中介映射，验证配对的存在唯一性；再测试一个丢失第二坐标的坏候选。

## 与 DeepSeek Harness / LLM 工业应用的联系

工具输入对象常由多个字段组成。积的观点说明组合字段既要可投影，也要保留足够信息以唯一重建；这比“恰好是一个 JSON 对象”更抽象。
