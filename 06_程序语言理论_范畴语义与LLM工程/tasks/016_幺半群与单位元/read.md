# 第 016 晚：幺半群与单位元

## 学习目标

## 精读导引

半群可折叠非空序列；加入单位元后才能统一处理空序列。必须核验左右两侧，非交换运算中一侧成立不保证另一侧。结合律与单位律使任意分块/括号得到同一结果。

## 必须完成的推导

结论类型：**THEOREM**。证明单位元唯一：若 `e`、`e'` 都是双侧单位元，则 `e=e·e'=e'`，第一步用 `e'` 的右/左单位性质时明确方向。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。计数、耗时和日志摘要若构成幺半群，可以把空批次解释为单位元，并安全合并 worker 局部结果；平均数本身通常不能只用一个标量组成这样的幺半群。
