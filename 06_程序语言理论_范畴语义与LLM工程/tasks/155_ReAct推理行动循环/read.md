# 第155晚：ReAct 推理—行动循环

## 目标与前置

- 目标：把 Thought、Action、Observation 视为受协议约束的交互轨迹。
- 前置：状态机、函数调用、基本提示设计。

## 阅读导引

逐行标注轨迹中哪些文本由模型产生，哪些由环境产生。把“想法”当不可信建议，把工具调用参数当待验证数据，避免将 ReAct 格式误认为安全边界。

## 核心推导

状态 s 包含问题与观察历史，策略 π(s) 产生 action，环境 T(s,a) 返回 observation。终止由显式 Finish 动作决定。可复现测试需固定 π 和 T，记录每次转移而非只验证最终答案。

## 工业联系与事实标签

- [THEOREM] 在确定性策略、确定性工具和有限步上限下，同一初态产生唯一有限轨迹。
- [EMPIRICAL] ReAct 论文在其问答与交互基准上报告了与若干 prompting 基线的比较结果。
- [INFERENCE] 工业 agent 应将行动协议、工具策略和自然语言推理分层。
- [OPEN] 隐藏推理、可审计解释与任务性能之间没有通用等价关系。

## 验收

成功、未知工具、步数边界均有断言；能区分 observation 与模型自述。
