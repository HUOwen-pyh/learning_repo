# 第 018 晚：幺半群同态与组合

## 学习目标

检查函数是否同时保持单位元和二元运算，并证明恒等同态与同态复合仍为同态。

## 精读导引

同态关心结构而非实现细节：`f(e)=e'`，且 `f(x·y)=f(x)·'f(y)`。先验证类型/载体，再验证定律。保持运算不能在所有情形自动推出保持单位元，尤其目标幺半群存在幂等元素时。

## 必须完成的推导

结论类型：**THEOREM**。给定 `f:M→N`、`g:N→P` 为同态，展开证明 `(g∘f)(e_M)=e_P` 和 `(g∘f)(xy)=(g∘f)(x)(g∘f)(y)`，每步标注使用 f 或 g 的同态律。
