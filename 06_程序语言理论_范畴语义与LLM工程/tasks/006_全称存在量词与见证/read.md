## 精读导引

阅读时把 `∀ x → B x` 读成对每个 `x` 返回 `B x` 证据的依赖函数；把 `Σ[ x ∈ A ] B x` 拆成第一投影的见证与第二投影的证据。有限枚举可验证有限域量词，但无限域需要证明规则。

## 必须完成的推导

结论类型：**THEOREM**。由 `p : ∃x.B(x)` 与 `f : ∀x.B(x)→C` 构造 `C`：拆出 `⟨w,bw⟩`，返回 `f(w)(bw)`。明确指出 `w` 不能逃逸到不含它的错误作用域。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。评测中的“存在一个失败用例”必须交付具体输入和复现证据；“所有样例通过”则依赖明确的样例域，不能偷换成所有可能输入。
