## 导读

问题不在多态或引用各自，而在创建同一可变位置的 effectful 表达式被复制出多个类型实例。值限制要求泛化对象已经是值，因此每种实例不会共享一次隐藏分配产生的单元。

## 今晚必须完成的推导或证明

逐步写出 `let r = ref (λx.x) in r := (λx.x+1); (!r) true` 被错误泛化时的类型推导，并标明运行时出错点。

把推导写在纸上或个人笔记中；关键规则名、每一步产生的约束以及失败位置必须可复查，不能只记录最终答案。

## 与 DeepSeek Harness / LLM 工程的联系

插件初始化、缓存句柄和 session 状态都是有分配效应的值。若类型层把一次初始化产生的对象当作任意类型重复解释，会制造与多态引用相同的共享别名风险。

这里的联系是工程建模用途，不声称 Harness 直接实现了本节全部形式系统。
