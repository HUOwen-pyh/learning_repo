# 第 025 晚：α 等价与名字规范化

## 学习目标

- 区分 binder 改名与自由变量改名。
- 判定两个项是否 α 等价。
- 用规范化表示避免“随便挑新名字”造成的比较不稳定。

## 精读导引

同时画 `λx.x`、`λy.y`、`λx.y` 的绑定边。前两个只有标签不同，第三个的 `y` 没有绑定边。规范化时按“离当前出现最近的 binder 距离”编码，不要按全局字符串替换。

## 必须完成的推导

1. 推导 `λx.λy.x` 与 `λa.λb.a` 的 α 等价。
2. 证明 `FV(t)` 在 α 改名下保持不变。
3. 给出 `λx.y` 与 `λy.y` 不 α 等价的反例理由。

结论类型：【基础等价】α 等价忘掉绑定变量拼写，但保留绑定结构与自由变量名字。

## 与 DeepSeek Harness / LLM 工业应用的联系

这是基础层联系：评测结构化程序时，临时变量名不同不应制造假差异。α 规范化是“语义相关字段”与“表面命名”分离的最小范例。
