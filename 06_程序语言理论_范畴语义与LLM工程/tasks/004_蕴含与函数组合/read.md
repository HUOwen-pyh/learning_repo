# 第 004 晚：蕴含与函数组合

## 学习目标

把蕴含证明视为把前件证据转换成后件证据的总函数，并用函数组合证明蕴含的传递性。

## 精读导引

函数体可以使用输入证据，但不能假设尚未得到的结论。重点跟踪恒等函数、组合与柯里化的类型，不要只看计算结果。有限样本测试只能发现组合实现错误，不能证明函数对无限输入总正确。

## 必须完成的推导

结论类型：**THEOREM**。从 `f : A→B` 与 `g : B→C` 构造 `λa.g(f(a)) : A→C`。再逐点展开证明结合律 `(h∘g)∘f = h∘(g∘f)`；若要说函数相等，明确使用外延性。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。工业评测常由解析、执行、验证多个变换组成；组合律帮助重构管线而不改变逐项语义，但副作用出现后需额外模型，不能直接套用纯函数结论。
