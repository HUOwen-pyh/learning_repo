## 精读导引

把否定看成消费 `A` 证据并产生不可能值的函数。`⊥` 没有居民，所以从它出发的消去函数没有实际分支。材料后半列出的排中律、双重否定消去等相互关系是经典扩展；不要把 Python 布尔求值自动当成构造性证明。

## 必须完成的推导

结论类型：**THEOREM**。构造 `A → ¬¬A`：给定 `a:A` 和 `na:A→⊥`，返回 `na(a)`。再说明反方向缺少从 `(A→⊥)→⊥` 中提取 `A` 的构造步骤。
