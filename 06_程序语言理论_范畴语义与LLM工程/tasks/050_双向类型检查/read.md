## 导读

双向系统把类型信息流写进规则形状：变量和应用通常向上综合，lambda 则在已知箭头类型时向下检查。注解是两个方向的桥，而不是装饰。实践脚本故意不让裸 lambda 综合类型，从而暴露算法的边界。

## 与 DeepSeek Harness / LLM 工程的联系

工具参数的 JSON Schema 类似“向下给定的期望类型”；模型产生的候选值类似待检查的项。区分 synth/check 能减少隐式猜测，也能给工具错误更精确的失败位置。

这里的联系是工程建模用途，不声称 Harness 直接实现了本节全部形式系统。
