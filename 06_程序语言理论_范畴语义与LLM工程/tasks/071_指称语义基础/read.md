## 导读

指称语义给每种语法构造一个数学对象，并要求语义按语法组合。变量的含义来自环境，常量不依赖环境，加法只组合两个子指称。脚本在有限状态上测试这些方程，而非把测试称为证明。

## 必做推导 / 证明

从定义展开 `⟦x+1⟧ρ`，再证明若 `ρ(x)=ρ'(x)`，则该表达式在两个环境中含义相同。

必须写出序、函数空间或不动点中的对象类型；不能把数学上的 bottom 与 Python 的偶然异常混为一谈。

## Harness / LLM 工程联系

系统提示、工具清单和 session projection 都可视作从结构化输入到模型上下文的函数。组合性使局部组件替换的影响范围可推理。

这里只使用组合性、近似和不动点作为分析工具，不声称 Harness 以该指称模型实现。
