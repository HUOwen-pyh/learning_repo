# 第 021 晚：交、并与 Galois 连接

## 学习目标

在幂集偏序中计算 meet/join，并通过等价式 `f(x)≤y ⇔ x≤g(y)` 核验一对 Galois 连接。

## 精读导引

在子集序中 meet 是交、join 是并，但应先用“最大下界/最小上界”定义验证。直接像与逆像满足 `image(S)⊆T ⇔ S⊆preimage(T)`，这是可执行的 Galois 连接实例。

## 必须完成的推导

结论类型：**THEOREM**。逐元素证明上述像/逆像等价：左到右取任意 `x∈S`；右到左取任意 `y∈image(S)` 并展开存在的原像见证。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。抽象解释、约束传播与具体/抽象状态之间常用 Galois 连接表达“最佳安全近似”；这里只验证有限集合实例，不声称目标仓库使用该理论。
