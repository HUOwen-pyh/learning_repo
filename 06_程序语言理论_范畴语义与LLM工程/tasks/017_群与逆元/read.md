# 第 017 晚：群与逆元

## 学习目标

## 精读导引

逆元要求左右乘都回到单位元。自然数加法有单位元却没有每个元素的自然数逆元；模 `n` 加法则有。Agda 记录展示结构继承：群包含幺半群证据，不应重复把每条定律混为一个布尔标签。

## 必须完成的推导

结论类型：**THEOREM**。由 `a·b=a·c` 左乘 `a⁻¹`，用结合律和单位律逐步推出 `b=c`。每一步标注使用的定律，不能直接“约掉 a”。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。某些状态变换可回滚，某些不可逆；只有真正有逆元的变换才能用“反向操作”恢复，日志删除、外部副作用等通常不构成群。
