## 精读导引

跟踪输入 `2 + 3 * 4`：先列 token，再按 `expr/term/atom` 三层文法画调用栈，最后画 AST。括号用于控制解析，却不必成为 AST 节点；优先级被树的嵌套位置保存。

## 必须完成的推导

1. 将歧义文法 `e ::= n | e+e | e*e` 分层为 `expr/term/atom`。
2. 推导 `2+3*4` 的唯一 AST 与结果 14。
3. 给出 `2+` 在哪一层失败以及错误位置。

结论类型：【工程方法】分层文法把优先级编码进非终结符，而非事后猜测。

## 与 DeepSeek Harness / LLM 工业应用的联系

这是基础但直接的工程联系：LLM 产生的 DSL、模板或工具参数先经过词法/语法边界再进入执行。错误必须在字符、token、AST 哪一层发生都可定位，才能形成稳定评测反馈。
