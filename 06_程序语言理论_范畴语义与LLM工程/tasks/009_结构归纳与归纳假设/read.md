# 第 009 晚：结构归纳与归纳假设

## 学习目标

把递归数据的每个构造子转成一个证明分支，正确选择归纳变量并使用归纳假设。

## 精读导引

把证明函数的两个方程与普通递归函数并排看：基础分支返回基础证据，后继分支递归取得归纳假设，再经同余提升。不要把“检查了很多 n”写成归纳证明，也不要在后继分支中假设待证命题本身。

## 必须完成的推导

结论类型：**THEOREM**。证明 `sum(0..n)·2=n(n+1)`：基础步化简为 `0=0`；归纳步从 `2S(n)=n(n+1)` 推出 `2(S(n)+n+1)=(n+1)(n+2)`，逐行写代数变换。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。对递归语法或执行树作正确性论证时，每个节点构造子都必须有分支；漏掉一种工具调用/终止节点，测试通过也不能补齐证明。
