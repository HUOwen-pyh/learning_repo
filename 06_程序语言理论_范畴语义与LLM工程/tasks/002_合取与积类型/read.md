# 第 002 晚：合取与积类型

## 学习目标

用一对证明构造 `A ∧ B`，并通过两个投影得到 `A` 与 `B`；能把引入规则和消去规则落实为代码接口。

## 精读导引

忽略 Agda 的 Unicode 输入方法，跟踪构造子 `⟨_,_⟩` 与投影。引入规则要求同时拥有两边证据；消去规则不能凭空产生新信息，只能取出已有分量。区分逻辑等价与值的字面相等：`A × B` 和 `B × A` 通常由互逆函数联系。

## 必须完成的推导

结论类型：**THEOREM**。给定 `p : A × B`，写出 `swap(p)=(p₂,p₁) : B × A`，再展开证明 `swap(swap(p))=p`。指出证明需要积值由两个分量完全决定。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。积类型对应“多个条件必须同时满足”的结构化结果，例如评分结果同时携带状态与证据；它提醒我们不能把一个布尔 `passed` 当作完整验证记录。
