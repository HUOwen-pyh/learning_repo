# 第 012 晚：自反传递闭包与多步关系

## 学习目标

从一步关系构造零步或多步关系，并用显式路径证书核验可达性。

## 精读导引

一步关系描述局部规则，多步闭包把局部步骤串成完整执行。证书必须保存中间节点并逐边检查；只检查起点和终点会接受不存在的跳跃。零长度路径证明 `x→*x`，不是没有证据。

## 必须完成的推导

结论类型：**THEOREM**。证明多步关系传递：对第一条多步证据归纳；零步时返回第二条，前缀一步时保留该步并递归组合尾部。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。一次 agent/tool 动作是一小步，完整评测运行是多步轨迹；重放器应逐步验证状态迁移，而不只相信最终输出。

- 23–35：推导多步传递性。
- 35–52：运行路径检查与 BFS 证书生成。

## 验收标准

- 零步证书被正确接受。
- 非相邻路径被拒绝，BFS 返回的每条边可重放。
- 能说明可达布尔值不等于路径证书。
