# 第 003 晚：析取与和类型

## 学习目标

用带标签的左/右构造子表示 `A ∨ B`，并理解消去析取为何必须覆盖两个分支。

## 前置任务

## 精读导引

对照积类型：积值同时有两项，和值恰有一项并带来源标签。析取消去不是选择方便的一边，而是对 `inj₁`、`inj₂` 穷尽分析。把“未知错误或成功”写成和类型，比用 `None` 或魔法整数更能保留信息。

## 必须完成的推导

结论类型：**THEOREM**。构造 `swap : A ⊎ B → B ⊎ A` 的两个分支，再逐构造子证明 `swap ∘ swap` 为恒等。说明漏掉任一分支时证明为何不完整。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。和类型适合表达互斥结果，如 `Accepted(evidence)` 或 `Rejected(counterexample)`；这比异常字符串更利于评测管线做穷尽处理。
