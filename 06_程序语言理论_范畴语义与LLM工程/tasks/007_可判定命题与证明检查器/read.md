# 第 007 晚：可判定命题与证明检查器

## 学习目标

实现一个返回“满足赋值或反例”的有限命题判定器，并区分判定过程、证明搜索和证书检查。

## 精读导引

注意 `Dec A` 不是单纯 `Bool`：成功支含 `A` 的证据，失败支含 `¬A`。今晚用有限真值表产生满足赋值或反例赋值；它判定的是有限命题公式的有效性，不是任意一阶逻辑。

## 必须完成的推导

结论类型：**THEOREM**。按公式结构证明求值函数终止；对 `And`、`Not` 各写一层归纳。然后说明穷举所有原子赋值为何给出有效式的完备反例搜索。

## 与 DeepSeek Harness / LLM 工业应用的联系

本晚仅建立基础。后续 Harness 的评测器应尽量输出可复核证书：成功可带执行轨迹，失败带最小反例。`UNKNOWN` 也必须与逻辑否定分开。

## 60 分钟安排

- 00–05：回忆 `Dec A` 两个分支。
- 05–23：精读指定范围。
- 23–35：按 AST 结构推导求值终止性。
- 35–52：运行判定器并检查证书。
- 52–58：加入零原子公式和非重言式反例。
- 58–60：完成第 1 周闭卷复盘。

## 验收标准

- 重言式返回成功证书，非重言式返回具体反例赋值。
- 能区分 SAT、有效性与单次求值。
- 能说出算法只覆盖有限命题逻辑。
