# 第156晚：Toolformer 自监督工具调用

## 目标与前置

- 目标：理解工具调用候选采样、执行与损失过滤，而非只学习调用格式。
- 前置：语言模型交叉熵、对数概率、数据过滤。

## 阅读导引

按“插入位置→采样 API call→执行→把结果插回→比较未来 token 损失→过滤”画流水线。辨别工具结果有用与调用本身语法正确是两个判据。

## 核心推导

对位置 i 的候选调用 c，比较不调用损失 L0 与插入结果后的 Lc。收益 Δ=L0−Lc；仅当 Δ 超过阈值才形成训练样本。阈值控制样本数量与精度，但并不证明因果正确。

## 工业联系与事实标签

- [THEOREM] 在本晚定义下，Δ>τ 与 Lc<L0−τ 等价。
- [EMPIRICAL] Toolformer 的工具使用能力和下游结果来自论文指定模型、API 与数据处理设置。
- [INFERENCE] 线上收集候选前必须脱敏、限权并缓存只读工具结果。
- [OPEN] 损失改善是否对应真实业务效用，需要任务级评测而非 token 指标替代。

## 严格 60 分钟

## 验收

正收益、负收益、恰等阈值断言通过；能解释 selection bias。
