# 第 07 晚：图灵机、配置与通用计算

## 今晚目标

实现单带机模拟器，区分机器、配置、一步关系与语言。

## 前置回忆（0–5 分钟）

有限状态机；可变数组/字典。 不看资料先写下相关定义；不会也先留下猜测，阅读后再用另一颜色修正。

## 精读（5–25 分钟）

确定图灵机在状态与带符号上选择写入、移动和下一状态。配置包含控制状态、无限带的有限非空部分和头位置；一步关系是局部的，但迭代可表达任意有效计算。识别器对非成员可能永不停止，判定器则对所有输入停止。多带、随机访问机等合理模型在多项式时间层面通常稳健，但具体时间会有多项式开销。通用机把“程序”也编码为数据，是可计算性与自指构造的起点。

**今晚唯一要守住的不变量：** 每步只读写头所在格，随后移动一格；停机状态没有后继。

**常见陷阱：** 用步数上限把“不知道”误报为拒绝；把模拟器的 Python 能力混入被模拟机器。

## 代码实战（25–50 分钟）

运行：

```powershell
python practice.py
```

模拟一台一元加一机；记录配置并检测重复配置作为某些循环的证据。 先读输出，再定位 `# 动手改造`；只改变一个因素并重新运行。不要删掉原有断言。

## 边界测试与复盘（50–60 分钟）

- 50–57 分钟：补一个最小正例、最小反例和一个边界输入。
- 57–60 分钟：闭卷写“定义 / 不变量 / 本例不能证明什么”各一句。
- 验收：输入 `111` 停机为 `1111`；明确超时、拒绝、接受三种状态。
