# 第 30 晚：综合项目：可验证的复杂性实验室

## 今晚目标

把归约、求解、证书和资源测量连成一条可复现实验管线。

## 前置回忆（0–5 分钟）

回顾第 1、9、11–13、16、19、25–29 晚的核心不变量。 不看资料先写下相关定义；不会也先留下猜测，阅读后再用另一颜色修正。

## 精读（5–25 分钟）

最终项目不试图用实验解决开放问题，而是建立“主张—模型—证据”闭环。管线读取小 CNF：先做 SAT 与 #SAT；再转为 CLIQUE 并核验双向答案；为 SAT 模型或 resolution refutation 输出可独立检查的证书；记录实例编码长度、搜索节点、峰值递归深度和墙钟时间。最后对同一实例族比较暴力、分支、参数化或随机策略。研究级习惯是把 theorem、assumption、empirical observation 三类标签写进报告，保留随机种子与反例。

**今晚唯一要守住的不变量：** 每个输出结论都由独立 verifier 检查；度量口径固定；超时写 UNKNOWN。

**常见陷阱：** 用同一段有 bug 的代码同时生成并验证证书；只选有利样本；由趋势外推复杂度类分离。

## 代码实战（25–50 分钟）

运行：

```powershell
python practice.py
```

运行项目脚本生成一份 JSON 风格报告；新增一个随机 CNF 族并复现实验。 先读输出，再定位 `# 动手改造`；只改变一个因素并重新运行。不要删掉原有断言。

## 边界测试与复盘（50–60 分钟）

- 50–57 分钟：补一个最小正例、最小反例和一个边界输入。
- 57–60 分钟：闭卷写“定义 / 不变量 / 本例不能证明什么”各一句。
- 验收：SAT/#SAT/CLIQUE 结果一致；证书可独立验证；能口头讲清至少三个开放问题的准确状态。
