## 精读（5–25 分钟）

两方分别持有 x、y，只通过比特通信计算 f(x,y)。本地计算免费，最坏通信位数是代价。确定性协议的每个叶子对应输入矩阵中的单色组合矩形；若需很多单色矩形覆盖，就需深协议树。Equality 有简单确定性 n 位协议，却用公共随机指纹做到 O(1) 位常误差；Disjointness 的随机通信仍为 Ω(n)。通信下界可转移到流式、数据结构和电路下界。代码对小函数矩阵求最大 fooling set 并构造协议。

**今晚唯一要守住的不变量：** 固定 transcript 的输入集合必须是 X'×Y'；叶子矩形内函数值相同。

**常见陷阱：** 把本地计算计入通信；公币/私币模型混用；fooling set 大小直接当精确复杂度。
