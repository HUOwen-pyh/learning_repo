# 第 03 晚：最大覆盖的指数衰减证明

## 目标

掌握“剩余差距按比例缩小”的贪心分析；证明选 `k` 个集合的 Maximum Coverage 达到 `1-(1-1/k)^k >= 1-1/e`；辨认 tie-breaking 与证明无关。

## 前置回忆（5 分钟）

证明不等式 `1-x <= e^{-x}`。设当前已覆盖价值为 `f(S_i)`，最优集合族为 `O`，为什么 `OPT-f(S_i)` 至多是 `O` 中各集合相对当前解的边际增益之和？

## 精读正文（20 分钟）

Maximum Coverage 给定集合族，至多选 `k` 个，使并集权重最大。令缺口 `Δ_i=OPT-f(S_i)`。覆盖函数满足次模性（越晚加入，边际增益不增）。最优的 `k` 个集合合起来至少补上 `Δ_i`，所以其中至少一个当前边际增益 `>=Δ_i/k`；贪心选最大边际，故 `Δ_{i+1}<= (1-1/k)Δ_i`。归纳得 `Δ_k <= (1-1/k)^k OPT <= e^{-1}OPT`，即 `f(S_k)>=(1-1/e)OPT`。复杂度朴素为 `O(kmn)`；位集可把并集计算降到机器字操作。

这里不是普通“交换一个元素而不坏”的 matroid 证明，而是 charging/衰减。关键不等式依赖覆盖函数的单调次模性；若元素有负权，单调性失效，贪心甚至会因“必须恰选 k 个”变差。若算法允许“至多 k 个”，应在最大边际非正时停。

反例方向：贪心保证不是 1。可构造第一步略大但横跨多个最优块的集合，使后续重复严重；`1-1/e` 对一般 Maximum Coverage 在标准复杂度假设下本质紧。实验的穷举 oracle 枚举 `m choose <=k`，只跑小规模。
