# 第 06 晚：从 matching 下界榨出顶点覆盖 2-近似

## 前置回忆（5 分钟）

## 精读正文（20 分钟）

取任意极大匹配 `M`，输出所有匹配边端点 `C`。可行性来自极大性：若边 `(u,v)` 两端均不在 `C`，则它与 `M` 中任意边不相交，可以加入，矛盾。下界来自匹配边两两点不交：任意顶点覆盖至少为每条匹配边贡献一个不同顶点，故 `|M|<=OPT`。于是 `|C|=2|M|<=2OPT`。扫描边并维护 used 集即可 `O(m+n)`。

星图直接给紧例：先选任意一条叶—中心边，算法取两个端点，OPT 只取中心，比值 2。改用最大匹配也仍只有一条，不能改善这个分析。二分图则有 Kőnig 定理 `maximum matching size = minimum vertex cover size`，通过增广路可从最大匹配恢复精确覆盖；一般图不成立，例如三角形最大匹配为 1、最小覆盖为 2。

不要把“matching 是下界”误推广到带权覆盖：一条边的两个端点权重可能悬殊，`2|M|` 已没有单位。带权 2-近似要用 LP/原始—对偶，将“每条边贡献”变成可累积的对偶变量。代码枚举全部边序，展示极大匹配选择会改变解，但最坏界保持。
