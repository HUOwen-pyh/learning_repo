# 第 14 晚：独立随机舍入、尾界与 alteration

## 目标

从分数覆盖解构造随机整数解；推导单元素漏盖概率与 union bound；理解期望成本、可行性高概率和修复（alteration）的区别。

## 前置回忆（5 分钟）

证明 `1-z<=e^{-z}`。若独立事件各以概率 `p_i` 失败，全部失败概率是多少？union bound 是否要求事件独立？

## 精读正文（20 分钟）

给 Set Cover 可行分数解 `x`，重复 R 次独立按 `x_S` 选集合，等价于最终选中概率 `q_S=1-(1-x_S)^R<=Rx_S`。对元素 e，漏盖概率
`Π_{S∋e}(1-x_S)^R <= exp(-RΣ_{S∋e}x_S)<=e^{-R}`。
对 n 个元素 union bound 得任一漏盖概率 `<=ne^{-R}`；取 `R=ln n+c`，成功概率至少 `1-e^{-c}`。期望成本 `Σc_Sq_S<=R·LP`，因此得到 `O(log n)` 随机近似的骨架。

“高概率可行且期望成本小”不自动保证同一次抽样两者同时好；可用 Markov + union bound、重复取最好可行样本，或 alteration：对每个漏盖元素补一个便宜集合并分析额外期望。Chernoff 对独立 Bernoulli 和给出指数尾：`Pr[X>=(1+δ)μ] <= [e^δ/(1+δ)^{1+δ}]^μ`；比 Markov 强，但变量相关时不能直接套。

代码用规则覆盖实例的分数解做 Monte Carlo，并总用 singleton 修复保证可行；理论概率断言基于公式，经验频率只作观察。反例：共享同一随机数实现“舍入”会产生强相关，单元素乘积公式失效。

## 代码实验

脚本构造环形覆盖：每元素被 d 个集合覆盖，令每个 `x=1/d`。随机 R 轮后统计漏盖元素，并用 singleton 修复；所有输出都验证可行。

## 验收

- 能推导 `ne^{-R}`。
- 能区分独立性在乘积公式与 union bound 中的角色。
- 不以 Monte Carlo 频率代替证明。
