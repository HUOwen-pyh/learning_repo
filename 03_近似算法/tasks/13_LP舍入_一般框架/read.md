# 第 13 晚：整数隙、阈值舍入与频率有界 Set Cover

## 目标

形成 LP-rounding 的统一模板；证明频率至多 `f` 的 Set Cover 通过 `1/f` 阈值获得 `f`-近似；理解整数隙既指导分析也限制该松弛。

## 前置回忆（5 分钟）

写 Set Cover LP：每个集合变量 `x_S∈[0,1]`，每个元素 `e` 约束 `Σ_{S∋e}x_S>=1`。定义元素频率 `f=max_e |{S:e∈S}|`。

## 精读正文（20 分钟）

给任意可行 LP 解，选择所有 `x_S>=1/f` 的集合。对元素 e，最多有 f 个覆盖它的变量，和至少为 1；鸽巢原理说明其中至少一个 `>=1/f`，所以舍入解可行。成本
`Σ_{selected}c_S <= Σ_{selected} f c_Sx_S <= f·LP <= f·OPT`。

统一模板是：写 ILP→删整数性得可解下界→寻找保可行的舍入规则→把每个整数选择收费到分数目标→报告比值和复杂度。切勿漏掉“怎样求 LP”；理论上可用内点法/椭球法多项式求有理 LP，本课程纯标准库代码只在极小实例枚举离散网格，且网格包含整数点，因此网格最优仍 `<=OPT`，但它不是一般 LP solver。

整数隙 `sup_I OPT(I)/LP(I)` 是任何“成本只相对该 LP 证明”的障碍。频率 f 的界在某些超图结构上可接近紧；要更好需要加强约束（如 lift-and-project）、随机/相关舍入或利用几何结构。反例：若把 f 错写成平均频率，高频元素的所有变量都可能低于阈值，输出不可行。

## 精确 60 分钟

- 00–05：写 LP 与频率。
- 05–25：复现可行性+成本两段证明。
- 25–45：运行网格 LP oracle 和阈值舍入。
- 45–55：把阈值改成 `1/(f-1)` 搜不可行例。
- 55–60：说出整数隙能与不能证明什么。

## 代码实验

脚本枚举 `{0,1/4,1/2,3/4,1}` 网格上的最小可行分数解，并与整数精确值比较；断言舍入成本 `<=f·gridLP<=f·OPT`。

## 验收

- 能用鸽巢原理证明可行。
- 能解释网格 oracle 和真正 LP 的差异。
- 能区分舍入比与整数隙。
