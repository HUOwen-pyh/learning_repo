# 第 05 晚：Set Cover 的调和数收费法

## 目标

证明加权集合覆盖贪心是 `H_n <= ln n+1` 近似；掌握按元素收费与对偶拟合两种视角；认识 `ln n` 阈值不是分析松弛的偶然。

## 前置回忆（5 分钟）

写出加权贪心规则：最小化 `cost(S)/|S∩U_uncovered|`。若某集合没有新元素，应如何处理？计算 `H_5`。

## 精读正文（20 分钟）

每次选集合 `S` 时，把成本均摊给新覆盖的 `q` 个元素，每个收费 `c(S)/q`，总收费恰为 ALG。固定最优解中的一个集合 `T`，按其元素被覆盖的次序看；当 `T` 还有 `r` 个未覆盖元素时，贪心候选 `T` 的单位价为 `c(T)/r`，故本轮被覆盖的 `T` 元素每个收费不超过它。于是 `T` 内收费至多 `c(T)(1/|T|+...+1)<=c(T)H_n`。把每个元素指定给一个覆盖它的最优集合，求和得 `ALG<=H_n OPT`。

复杂度朴素 `O(mn·#choices)`，可维护未覆盖计数加速。加权前提是成本非负；零成本集合应先全部取走。若 universe 中元素不属于任何集合，实例不可行，算法必须报错而非死循环。

下界方面，Feige 证明在 NP 没有 `n^{O(log log n)}` 时间算法的假设下，不能以 `(1-o(1))ln n` 更好地近似 Set Cover；后续工作在更标准假设下细化。不要把这一条件误写成仅 `P!=NP` 的同一句定理。经典分层集合族能让贪心接近调和数，说明收费分析有结构性依据。
